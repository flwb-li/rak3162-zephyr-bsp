# 硬件引脚分配表（整理版）

## 1. SX1262 LoRa 模块

| 功能      | 引脚   | 说明             |
|----------|--------|----------------|
| SCK      | P1.11  | SPI 时钟        |
| MOSI     | P1.10  | SPI 主出从入    |
| MISO     | P1.09  | SPI 主入从出    |
| CS/NSS   | P1.12  | SPI 片选        |
| RESET    | P0.04  | sx1262复位       |
| BUSY     | P1.13  | 模块忙标志      |
| ANT_SW   | P0.00  | lora天线开关      |
| DIO1     | P0.01  | 中断/数据标志   |
| DIO2     |        | lora 射频TX/RX切换   |
| DIO3     |        | TCXO 1.8V  |

## 2. UART 接口

| UART 路径 | TX     | RX     | 说明       |
|-----------|--------|--------|------------|
| UART0     | P1.06 | P1.07  | debug UART    |
| UART1     | P2.08 | P2.07  | Secondary UART    |

## 3. I²C 接口

| 功能 | 引脚  | 说明      |
|------|-------|-----------|
| SDA  | P0.02 | 数据线    |
| SCL  | P0.03 | 时钟线    |

## 4. 预留 SPI 接口

| 功能 | 引脚  | 说明      |
|------|-------|-----------|
| CS   | P2.05 | SPI 片选  |
| SCK  | P2.01 | SPI 时钟  |
| MISO | P2.04 | SPI 主入从出 |
| MOSI | P2.02 | SPI 主出从入 |

## 5. NFC 接口

| NFC 引脚 | 引脚  | 说明 |
|-----------|-------|------|
| NFC1      | P1.02 |      |
| NFC2      | P1.03 |      |

## 6. 模拟输入 (AIN)

| AIN  | 引脚  | 说明     |
|------|-------|----------|
| AIN0 | P1.04 | 模拟输入 |
| AIN1 | P1.05 | 模拟输入 |

## 7. LED
| led  | 引脚  | 说明     |
|------|-------|----------|
| LED1 | P2.09 |  |
| LED2 | P2.10 |  |


## 8. 通用 GPIO

| GPIO  | 引脚  | 说明     |
|-------|-------|----------|
| GPIO1 | P1.08 |          |
| GPIO2 | P1.14 | 可做模拟输入使用 AIN7 |
| GPIO3 | P2.03 |          |
| GPIO4 | P2.06 |          |

## 8. nrf54l15 hfxo lfxo

**HFXO:** High-Frequency Crystal Oscillator，高频晶体振荡器，使用外部32M晶振

**LFXO:** Low-Frequency Crystal Oscillator，低频晶体振荡器，使用外部32.768k 晶振

使用外部晶振，需要内部电容进行匹配，[配置文件](../rak3162_nrf54l15_cpuapp.dts)
