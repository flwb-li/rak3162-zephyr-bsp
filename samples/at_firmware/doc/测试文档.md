## 1. 测试前准备

### 1.1 硬件

- RAK3162 样机、稳定电源（功耗测试建议串联电流表 / 电源分析仪）
- USB–UART（接到 AT UART）
- LoRaWAN 网关（EU868）及可查看上下行的 Network Server
- （可选）示波器 / 逻辑分析仪：观察 RF 窗口、唤醒时序

### 1.2 固件与工具

- 烧录待测 `zephyr.hex`
- 串口工具（支持发送十六进制 / 单字节唤醒）
- 网关侧已添加设备密钥（见下），或使用现场实际密钥覆盖

### 1.3 出厂测试密钥（当前固件临时种子）

NVS 中缺凭证时，固件会写入临时测试值（**量产前需移除**）：

```text
DevEUI  = 0011223344556677
AppEUI  = 0011223344556677
AppKey  = 00112233445566778899AABBCCDDEEFF
```

NS 侧请先按上述密钥建档；也可用 `AT+DEVEUI` / `AT+APPEUI` / `AT+APPKEY` 改为现场密钥后 `ATZ`。

### 1.4 主机唤醒协议（Join 成功后必读）

Join 成功后，空闲期间 UART 会挂起，RX 脚用 **GPIO Sense** 唤醒。首字节会丢失，请按两阶段操作：

1. 发送唤醒字节（如 `\r` 或 `0x00`）
2. 等待串口出现 `+EVT:UART_WAKE`
3. 再发送真实 AT 命令

## 2. 测试要点（必读）

| 编号 | 要点 | 说明 |
|------|------|------|
| P1 | System ON idle ≠ `AT+SLEEP` | 自动周期间为空闲（RAM 保持、可 Sense 唤醒）；`AT+SLEEP` 为 System OFF（冷启动类唤醒） |
| P2 | 自动上报固定非确认 | `AT+SENDINT` 周期上报 **忽略** `AT+CFM`；仅手动 `AT+SEND` 受确认模式影响 |
| P3 | 自动上报内容 | Port **2**，载荷为 4 字节大端 **FCnt** |
| P4 | UART 首字节丢失属预期 | Sense 唤醒设计如此；等 `+EVT:UART_WAKE` 后再发正式 AT |
| P5 | 空闲电流目标量级 | Sense + UART 挂起约 **~5 µA** 量级（板级差异以实测为准） |
| P6 | 占空比 | EU868 下可能 `-EAGAIN`，固件会延后重试，**不发假** `+EVT:TX_DONE` |
| P7 | ADR 默认开启 | 启动按 NVS/`AT+ADR` 启用 ADR（默认 ON）；不再强制 DR4 |
| P8 | 无跨复位会话保持 | `ATZ` / 掉电 / `AT+SLEEP` 唤醒后 **不恢复**旧 OTAA 数据会话；需重新 Join（`join_auto=1` 自动） |
| P9 | `AT+JOIN=1` 可强制重入网 | 已 Join 时再发 `AT+JOIN=1:...` 会清当前会话并重新 OTAA |
| P10 | `AT+JOIN=0:0` | 只停 Join / 写 `join_auto=0`，**不离网**、**不停** `SENDINT` |
| P11 | 改凭证只写 NVS | `AT+APPEUI` 等立即持久化，但不会自动断开当前会话 |
| P12 | 静默启动 | `CONFIG_LOG=n` / 无 boot banner；复位后无启动打印，发 `AT` 验证存活 |
| P13 | Join 前 vs Join 后 | Join 前 AT UART 保持可收；Join 后空闲才挂起 + Sense |
| P14 | 凭证 | 缺省 `001122…` 仅为功耗/联调方便；正式测试请在 NS 核对是否冲突 |
