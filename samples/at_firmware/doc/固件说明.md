# RAK3162 AT 固件说明（讲解用）

| 项 | 内容 |
|----|------|
| 产品板卡 | RAK3162（`rak3162/nrf54l15/cpuapp` + 板载 SX1262） |
| 固件样本 | `samples/at_firmware` |
| 文档日期 | 2026-08-14 |
| 相关文档 | `AT_COMMANDS.md`、`LOW_POWER.md`、`测试文档.md`、`boards/rak3162/doc/hardware_pins.md` |

本文面向讲解：说明当前固件的分层框架、启动流程、关键文件与函数职责、AT 命令映射、业务数据路径与低功耗行为。

---

## 1. 设计目标与总体结论

当前固件是面向产品的 **OTAA Class A AT 固件**，不是完整 RUI3 克隆，而是 RUI3 风格的实用子集。

主要能力：

- AT 串口配置 / 查询 / 控制
- LoRaWAN OTAA 入网与上下行
- 可配置自动上报（`AT+SENDINT`）
- LoRa P2P
- RF 窗口外 System ON 低功耗空闲
- 显式 `AT+SLEEP` 进入 System OFF

刻意不做 / 尚未做：

- ABP、Class B/C、`AT+RETY`、产测 CW、串口 DFU（无 MCUboot）
- 跨复位的 LoRaWAN **数据会话保持**（对齐 RUI3：复位后重新 OTAA；DevNonce 仍持久化）

## 2. 分层框架

固件按 RUI3 思路拆成三层：

```text
┌─────────────────────────────────────────────────────────┐
│ Application：samples/at_firmware/src/main.c             │
│  - 启动顺序、测试凭证种子、自动 Join、周期上行、AT+SENDINT │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│ Board runtime：lib/rak3162_runtime                      │
│  - NVS、LED、次要总线 PM、Sense 唤醒、board/ops 绑定      │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│ Framework：modules/rak-fw                               │
│  - AT 解析/命令表、UART 端口、LoRaWAN/P2P 服务            │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│ Zephyr / 硬件                                           │
│  - LoRaMAC-node、SX1262(spi22)、Settings/NVS、GRTC      │
└─────────────────────────────────────────────────────────┘
```

| 层 | 目录 | 职责 |
|----|------|------|
| 应用策略 | `samples/at_firmware` | 产品行为：何时 Join、何时自动发包、SENDINT |
| 板级运行时 | `lib/rak3162_runtime` | 把板级能力接到框架（存储/灯/总线/Sense/绑定） |
| 固件框架 | `modules/rak-fw` | 可复用 AT + LoRa 服务，尽量不绑死某一板 |
| OS/驱动 | Zephyr + 板级 DTS | 协议栈、外设、定时器、持久化 |

讲解时可强调：**AT 命令大多在 rak-fw；自动上报周期是应用层策略，不是协议栈自带功能。**

## 4. 启动调用链

`main()` 顺序（`samples/at_firmware/src/main.c`）：

```text
main()
  rak_at_port_init()              # UART 异步 RX
  board_at_lp_init()              # P1.07 Sense 钩子
  rak3162_storage_init()          # Settings/NVS
  rak3162_storage_bind_at_cfg()   # AT 配置后端
  rak_fw_lora_p2p_init()
  rak_fw_lorawan_init()
  radio_bind_at()                 # 绑定 ops + 事件到 AT
  rak_at_init()                   # ATZ / ATE
  rak_at_register_standard_commands()  # system + lorawan + p2p
  rak3162_bus_pm_suspend()        # 启动即挂起次要总线
  rak3162_led_start()
  rak_at_start()                  # RX worker 线程
  app_policy_start()              # SENDINT + autojoin
  k_sleep(K_FOREVER)
```

`app_policy_start()`：

1. 初始化 `uplink_work` / `join_retry_work`
2. 注册 `on_join_status` / `on_send_done`
3. 注册 `AT+SENDINT`
4. 调用 `autojoin_on_boot()`

说明：当前 `CONFIG_LOG=n`、`CONFIG_BOOT_BANNER=n`，复位后**无启动打印**；用 `AT` 确认存活。

## 5. 关键函数一览（按文件）

### 5.1 应用层 `samples/at_firmware/src/main.c`

| 函数 | 作用 |

| `main()` | 全局启动入口 |

## 6. AT 命令 → 处理函数映射

注册方式：`rak_at_register_command("NAME", handler, help)`，用户输入 `AT+NAME`。

| AT 命令 | Handler | 文件 |
|---------|---------|------|
| `ATZ` | `cmd_atz` | `rak_at_core.c` |
| `ATE0` / `ATE1` | `cmd_ate` | `rak_at_core.c` |
| `AT+SN` | `cmd_atsn` | `rak_at_cmd_system.c` |
| `AT+VER` | `cmd_atver` | `rak_at_cmd_system.c` |
| `AT+RTC` | `cmd_rtc` | `rak_at_cmd_system.c` |
| `AT+SLEEP` | `cmd_sleep` | `rak_at_cmd_system.c` |
| `AT+DEVEUI` | `rak_at_cmd_deveui` | `rak_at_cmd_lora.c` |
| `AT+APPEUI` | `rak_at_cmd_appeui` | `rak_at_cmd_lora.c` |
| `AT+P2P` / `PRECV` / `PSEND` | `rak_at_cmd_p2p` 等 | `rak_at_cmd_lora.c` |
| `AT+APPKEY` / `NWKKEY` | `rak_at_cmd_appkey` 等 | `rak_at_cmd_lorawan.c` |
| `AT+NWM` / `BAND` / `ADR` | 对应 cmd | `rak_at_cmd_lorawan.c` |
| `AT+CFM` / `CFS` / `NJS` / `NJM` | 对应 cmd | `rak_at_cmd_lorawan.c` |
| `AT+JOIN` | `rak_at_cmd_join` | `rak_at_cmd_lorawan.c` |
| `AT+SEND` | `rak_at_cmd_send` | `rak_at_cmd_lorawan.c` |
| `AT+CLASS` / `RECV` | 对应 cmd | `rak_at_cmd_lorawan.c` |
| `AT+SENDINT` | `cmd_sendint` | **`main.c`（应用层）** |

注册时序：

1. `rak_at_init()` → `ATZ` / `ATE`
2. `rak_at_register_standard_commands()` → system + LoRaWAN + P2P
3. `app_policy_start()` → `SENDINT`

### `AT+JOIN` 四参数（讲解常问）

`AT+JOIN=<cmd>:<auto>:<interval_s>:<attempts>`

| 参数 | 含义 |
|------|------|
| cmd | `1` 开始 Join；`0` 停止 Join |
| auto | `1` 复位后自动 Join；`0` 不自动（写 NVS） |
| interval_s | 重试间隔秒 |
| attempts | 次数；`0`=一直重试 |

注意：

- `AT+JOIN=0:0` **不离网**、**不停** `SENDINT`
- `AT+JOIN=1` 即使已 Join 也会清会话并重新 OTAA
- 改 `APPEUI` 等只写 NVS，不会自动离网

## 7. 业务数据路径

### 7.1 自动入网 + 自动上报

```text
boot
  → autojoin_on_boot()
  → join_otaa_async()
  → +EVT:JOINED
  → on_join_status(true)
  → uplink_work
  → 读 FCnt → AT+SEND 等价：Port2 / 4字节 / UNCONFIRMED
  → +EVT:TX_DONE
  → on_send_done → System ON idle → GRTC 延时 → 下一包
```

- 间隔：`AT+SENDINT`（默认 10 s；`0`=关闭自动上报）
- 自动上报**忽略** `AT+CFM`
- 未 Join：`join_retry_work` 约 10 s 后重试 autojoin

### 7.2 手动 `AT+SEND`

```text
AT+SEND=<port>:<hex>
  → rak_at_cmd_send
  → send_async（CFM 决定确认/非确认）
  → +EVT:TX_DONE / SEND_CONFIRMED_OK|FAILED
```

### 7.3 改凭证后如何重入网（当前策略）

```text
AT+APPEUI=... / AT+APPKEY=...   # 只写 NVS
AT+JOIN=1:1:8:0               # 强制新 OTAA
# 或
ATZ                           # 冷启动；join_auto=1 时自动 OTAA
```

## 8. 低功耗与 UART 唤醒

### 8.1 System ON idle（自动周期默认路径）

| 部件 | 行为 |
|------|------|
| MCU | tickless WFI，RAM 保持 |
| SX1262 | warm sleep（`WarmStart=1`） |
| spi22 / ANT_SW / 次要总线 | RF 窗外挂起/关闭 |
| AT UART | 默认挂起 + P1.07 Sense |
| 定时 | GRTC 调度下一包 |

### 8.2 System OFF（`AT+SLEEP`）

- `sys_poweroff()`，RAM 丢失
- 可选 `AT+RTC` GRTC 唤醒后冷启动
- 需重新 OTAA（`join_auto=1` 时自动）

### 8.3 两阶段 AT 唤醒（Join 后空闲）

```text
1. 发唤醒字节（\r / 0x00）——该字节丢失
2. 等 +EVT:UART_WAKE（固件 settle ~50 ms 并 purge 脏数据）
3. 再发真实 AT
```

`KEEP_RX=y` 可避免丢字节，但空闲电流约升到 ~155 µA。

## 9. 持久化（NVS）

Settings 根：`rak3162`

| Key | 内容 |
|-----|------|
| `rak3162/active_cfg` | 凭证、NWM、BAND、ADR、JOIN 参数等 |
| `rak3162/send_interval_s` | 自动上报周期（独立 key） |

LoRaMAC 自身 NVM：主要用于 **DevNonce** 单调；**数据会话不跨复位恢复**。

缺省策略摘要：

- BAND=EU868（4）
- ADR=ON
- join_auto=1（可被 `AT+JOIN=0:0` 改掉）
- SENDINT=10

## 10. `prj.conf` 讲解要点

| 配置 | 含义 |
|------|------|
| `CONFIG_LOG=n` / `BOOT_BANNER=n` | 静默启动，利于测电流 |
| `CONFIG_PM_DEVICE` + `TICKLESS_KERNEL` | 外设 PM + GRTC idle |
| `CONFIG_POWEROFF=y` | 支持 System OFF |
| `CONFIG_RAK_AT_UART_LP=y` | UART 低功耗进出 |
| `CONFIG_RAK_AT_UART_LP_KEEP_RX=n` | Sense 唤醒路径 |
| `CONFIG_LORAWAN` + 多 region | loramac-node |
| `CONFIG_SETTINGS` + `NVS` | 配置持久化 |
| `CONFIG_BT=n` | 本固件不用蓝牙 |

烧录：模组无 USB，当前无串口 DFU；开发期用 **SWD（J-Link 等）** 烧 `zephyr.hex`。
